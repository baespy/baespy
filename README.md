### About

```text
baespy ~ $
│
├── focus       Backend systems, FiveM resources & game interfaces
├── enjoy       clean menus, small details, useful tools
└── approach    build → try → learn → improve
```

I like turning ideas into something I can actually use — a gameplay feature,
a clearer menu, backend logic, or a small tool that makes working on a server easier.

I work with Lua, Python, C++, and C# for backend and server-side development,
alongside JavaScript, HTML, and CSS for interfaces.

I also use MySQL and MongoDB for application data, and Nginx for serving sites
and setting up reverse proxies. I'm comfortable working with these tools and
keep learning more about database queries, configuration, and troubleshooting
as each project brings up something new.

I've worked on FiveM servers with 1,000+ players, learning from the problems
that come up when a server gets busy. My work has included reducing resource
usage in resmon and tracking down and fixing memory leaks related to models
and how resources load and release them.

I'm still learning, especially when it comes to performance and memory issues.
I like taking things step by step: investigate, try a fix, measure the result,
and learn from what worked and what didn't.

### Selected Work

#### FiveM Resource Development

Developed and improved FiveM resources using Lua and MySQL, focusing on
server-side logic, data handling, and connecting resources. Learned through
practical work on servers with 1,000+ players.

#### Performance & Memory Troubleshooting

Worked on reducing resource usage measured through resmon and fixing
model-related memory leaks. Took a step-by-step approach: investigate the
issue, try a fix, and compare the results.

#### infrontofx — Development Tools & References

Created **[infrontofx-skill ↗](https://github.com/baespy/infrontofx-skill)** and
**[infrontofx-fivem ↗](https://github.com/baespy/infrontofx-fivem)** to organize
development conventions, examples, and tools for writing, debugging, and
reviewing FiveM resources. These projects continue to evolve as I learn from
everyday development.
