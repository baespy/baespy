### About

```text
baespy ~ $
│
├── focus       Backend systems, FiveM resources & game interfaces
├── enjoy       clean menus, small details, useful tools
└── approach    build → try → learn → improve
```

I like turning ideas into something I can actually use — a gameplay feature,
a clearer menu, backend logic, or a small tool that makes working on a server easier.

I work with Lua, Python, C++, and C# for backend and server-side development,
alongside JavaScript, HTML, and CSS for interfaces.

I've worked on FiveM servers with 1,000+ players, learning from the problems
that come up when a server gets busy. My work has included reducing resource
usage in resmon and tracking down and fixing memory leaks related to models
and how resources load and release them.

I'm still learning, especially when it comes to performance and memory issues.
I like taking things step by step: investigate, try a fix, measure the result,
and learn from what worked and what didn't.
